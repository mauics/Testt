Save reports to CSV

Every PC sends a report (CPU, RAM, disk…) every few seconds. This saves that history to CSV Files/Reports on the server.
Loading…

Save all CSV files

Saves everything at once into the server's CSV Files folder. Choose below what to clear from the database after it's saved.
Repair Log, PMS History and Part Changes are written as things happen, so they're always up to date already. Nothing is deleted unless every file saved.

Remove PC data

Deletes the chosen PCs' reports and expected parts from the database, so they leave the Inventory and Monitoring — e.g. a PC that was replaced or taken out of the lab. Pickups, repair/PMS history and the CSV files are kept. If a PC's agent is still running, it comes back as new with its next report. Tip: save its reports first with Save reports or Save all CSV.
